### Release 1
# Archival nodes of the first experiment machine

Original release: December 2023. Updated: February 2026.

Now, Archival Nodes of the First Experiment Machine is a workbench. A layout of on-chain proposals, details culled from the chain and laid out, tattered but hopeful, for all to see.

*Tokens recapitulate a history. Ideas encoded in proposals and actualized by collective assent.*

Original renderer can be [seen here](../assets/archives.png?raw=True). This renderer used a deterministic but simpler SVG display to showcase the proposals from the DAO. Collectors uncovered this as they explored the rendering and the chain, some notes on their discoveries below.

*Deterministic layout, linking symbols and submissions. All color, position variation mapped to chain data (except archive cursor).*

In early 2024 collectors and artist simulated the first experiment machine, proposing updates to a project. This is saved here for posterity.

🚧⭐️ Fork of this renderer [passed](https://snapshot.org/#/perpetual.takens.eth/proposal/0x2309dd0e2961482d612aded48c25ce9caa04c0a50d94b13055e4bb3862b0de79). Please [see](proposals.md) `proposals.md` for details.
